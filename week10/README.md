# 문자 검사 함수 사용하기

## 📌 설명
C언어의 `ctype.h` 헤더 파일을 이용하여 다양한 문자 검사 함수를 실습하는 프로그램입니다.

## 🔍 사용 함수
- `isalpha()` : 알파벳 검사
- `isupper()` : 대문자 검사
- `islower()` : 소문자 검사
- `isdigit()` : 숫자 검사
- `isalnum()` : 문자 또는 숫자 검사
- `isxdigit()` : 16진수 검사
- `ispunct()` : 구두점 검사
- `isprint()` : 인쇄 가능 문자 검사
- `iscntrl()` : 제어 문자 검사
- `isascii()` : ASCII 문자 검사

# 문자열 처리 함수 사용하기

## 📌 설명
C언어의 `string.h` 헤더 파일을 이용하여 문자열을 처리하는 다양한 함수를 실습하는 프로그램입니다.

## 🔍 사용 함수
- `strlen()` : 문자열 길이 확인
- `strcpy()` : 문자열 복사
- `strncpy()` : 지정한 길이만큼 문자열 복사
- `strcmp()` : 문자열 비교
- `strncmp()` : 지정한 길이만큼 문자열 비교
- `strcat()` : 문자열 연결
- `strncat()` : 지정한 길이만큼 문자열 연결
- `strchr()` : 특정 문자 검색
- `strstr()` : 특정 문자열 검색

# 이진 탐색(Binary Search)

## 📌 설명
정렬된 배열에서 원하는 값을 효율적으로 찾기 위해 이진 탐색 알고리즘을 사용하는 프로그램입니다.

## 🔍 주요 기능
- `binarySearch()` : 배열에서 원하는 값 검색
- 중간값을 기준으로 탐색 범위를 절반씩 줄임
- 값을 찾으면 해당 인덱스 반환
- 값을 찾지 못하면 `-1` 반환
