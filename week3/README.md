# 윤년 계산 프로그램 (work1.c)

사용자가 입력한 연도가 윤년인지 판별하는 C언어 프로그램이다.

## 실행 조건
- 연도를 입력받는다.
- 4로 나누어떨어지고 100으로 나누어떨어지지 않거나, 400으로 나누어떨어지는 해를 윤년으로 판별한다.

# 학점 판별 프로그램 (work2.c)

## 설명
- 점수를 입력받아서 A부터 F까지 학점 매겨주는 프로그램임.
- 다중 if-else문 써서 범위별로 조건 처리함.

## 코드 핵심
- `scanf`로 0~100 사이 점수 받기
- `if (outcome >= 90)` 부터 시작해서 차례대로 조건 체크

## 실행 화면 예시
- 95점 넣으면 -> `학점은: A`
- 85점 넣으면 -> `학점은: B`

# work3.c

## 📝 설명
- while문이랑 scanf 리턴값(EOF) 써서 숫자 계속 입력받는 프로그램임.
- 다 입력하고 나서 `Ctrl + Z` 누르면 끝남. 그동안 입력했던 숫자들 싹 다 더해서 총합 보여줌.

## 💻 포인트
- `while (scanf("%d", &n) != EOF)` 로 입력 끝날 때까지 계속 돌리기
- sum 변수에 입력값 계속 누적해서 더해주기
