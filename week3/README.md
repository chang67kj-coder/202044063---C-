# 3주차 C언어 실습 과제

3주차에 진행한 조건문 및 반복문 실습 코드 모음입니다.

---

## 1. work1.c (윤년 계산)
- **설명**: 사용자가 입력한 연도가 윤년인지 판별하는 프로그램
- **조건**: 
  - 4로 나누어떨어지고 100으로 나누어떨어지지 않거나
  - 400으로 나누어떨어지는 해

---

## 2. work2.c (switch 문을 이용한 학점 판별)
- **설명**: 점수를 입력받아 `switch`문으로 학점을 매겨주는 프로그램
- **핵심**: 
  - 점수를 10으로 나눈 몫(`outcome / 10`)을 활용해 구간별로 `case` 분기 처리
  - 90점대와 100점은 `case 10`, `case 9`를 묶어서 동일하게 'A' 학점으로 처리

---

## 3. work3.c (정수 합계 구하기)
- **설명**: `while`문과 `EOF`를 이용해 숫자를 계속 입력받고 합계를 구하는 프로그램
- **핵심**: 
  - `while (scanf("%d", &n) != EOF)`로 반복 입력 받기
  - `Ctrl + Z` 입력 시 종료 후 총합 출력

---
## 4. work4.c (정수의 각 자릿수 곱 구하기)
- **설명**: 교재의 자릿수 합 예제를 응용해, 입력받은 정수의 각 자릿수들을 서로 곱한 값을 구하는 프로그램
- **핵심**: 
  - `while (number != 0)` 문을 통해 0이 될 때까지 각 자릿수 분리
  - 곱셈 연산이므로 결과 변수(`product`)는 **1**로 초기화(`*= number % 10`)
---
## 5. work5.c (중첩 반복문 패턴 출력)
- **설명**: 다중 `for`문을 이용해 행이 바뀔 때마다 `#` 개수가 늘어나는 패턴을 출력하는 프로그램
- **핵심**: 
  - 외부 `for`문은 출력할 행의 전체 개수를 결정
  - 내부 `for`문은 각 행에서 찍어낼 `#`의 개수를 조절
