# 3주차 C언어 실습 과제

3주차에 진행한 조건문 및 반복문 실습 코드 모음입니다.

---

## 1. work1.c (윤년 계산)
- **설명**: 사용자가 입력한 연도가 윤년인지 판별하는 프로그램
- **조건**: 
  - 4로 나누어떨어지고 100으로 나누어떨어지지 않거나
  - 400으로 나누어떨어지는 해

---

## 2. work2.c (학점 판별)
- **설명**: 점수를 입력받아 A부터 F까지 학점을 매겨주는 프로그램
- **핵심**: 다중 `if-else`문을 사용해 점수 구간별 조건 처리

---

## 3. work3.c (정수 합계 구하기)
- **설명**: `while`문과 `EOF`를 이용해 숫자를 계속 입력받고 합계를 구하는 프로그램
- **핵심**: 
  - `while (scanf("%d", &n) != EOF)`로 반복 입력 받기
  - `Ctrl + Z` 입력 시 종료 후 총합 출력
