# 🎲 숫자 맞추기 게임

C언어 수업 시간에 실습한 숫자 맞추기 프로그램입니다. 
1부터 100 사이의 랜덤 숫자를 맞출 때까지 업다운 힌트를 줍니다.

## 사용한 문법
- `rand()`, `srand()`: 랜덤 숫자 생성
- `while(1)`: 정답을 맞출 때까지 무한 반복
- `if-else`: 입력값과 정답 비교 (업/다운)
--------------------------------------------------
# ➕ 가변 매개변수 합계 구하기

C언어 수업 시간에 실습한 가변 매개변수(`stdarg.h`) 활용 프로그램입니다.
인자의 개수가 정해지지 않았을 때, 여러 개의 숫자를 입력받아 모두 더해주는 `sum` 함수를 구현했습니다.

## 사용한 문법
- `<stdarg.h>`: 가변 매개변수를 사용하기 위한 헤더 파일
- `va_list`: 매개변수 목록을 저장하는 변수 타입
- `va_start()`: 가변 매개변수 읽기 시작 및 초기화
- `va_arg()`: 다음 매개변수의 값 가져오기
- `va_end()`: 가변 매개변수 사용 종료 및 정리
---------------------------------------------------
