# C언어 배열과 함수 전달 예제

이 코드는 함수에 변수를 전달할 때와 배열을 전달할 때의 차이를 보여줍니다.

1. change_value 함수 (변수 전달)
값을 복사해서 전달하므로 함수 안에서 값을 변경해도 원본은 변하지 않습니다.

2. change_array 함수 (배열 전달)
배열의 주소를 전달하므로 함수 안에서 값을 변경하면 원본 배열도 함께 변합니다.

# 주사위 숫자 빈도 계산 프로그램

주사위를 10번 던져서 각 숫자가 몇 번 나왔는지 세어주는 프로그램입니다.

[주요 기능]
- 사용자에게 1부터 6 사이의 주사위 숫자를 총 10번 입력받습니다.
- 배열의 인덱스를 활용하여 입력된 숫자의 횟수를 누적합니다.
- 범위(1~6)를 벗어난 숫자를 입력하면 경고 메시지를 띄우고 다시 입력받습니다.
- 입력이 모두 끝나면 1부터 6까지 각각 몇 번 나왔는지 화면에 출력합니다.

# 점수대별 학생 수 계산 프로그램

학생들의 점수를 입력받아 10점 단위 구간별로 학생 수를 세어주는 프로그램입니다.

[주요 기능]
- 0이 입력될 때까지 점수를 계속해서 입력받습니다.
- 점수를 10으로 나눈 몫을 이용해 10점 단위로 점수대를 분류합니다.
- 1부터 100 사이의 범위를 벗어난 점수를 입력하면 경고 메시지를 띄웁니다.
- 입력이 종료되면 해당하는 학생이 1명 이상인 점수대만 화면에 출력합니다.

# 숫자의 개수 (C언어)

## 문제 개요
세 개의 자연수 A, B, C를 입력받아 곱한 결과에 0부터 9까지의 숫자가 각각 몇 번 쓰였는지 카운트하여 출력하는 프로그램입니다.

## 주요 풀이 아이디어
1. 자료형 선택: 세 수의 곱이 클 수 있으므로 오버플로우 방지를 위해 long long 자료형을 사용했습니다.
2. 자릿수 추출: 반복문 안에서 나머지 연산으로 마지막 자리 숫자를 구하고, 나누기 연산으로 자릿수를 줄여가며 확인합니다.
3. 빈도수 카운트: 크기가 10인 배열을 선언하고, 각 자릿수 숫자를 인덱스로 사용하여 등장 횟수를 기록합니다.
4. 결과 출력: 0부터 9까지의 인덱스를 순회하며 각 숫자의 등장 횟수를 차례대로 출력합니다.

# 정수형 배열 정렬하기 

## 문제 개요
주어진 정수형 배열의 원소를 버블 정렬(Bubble Sort) 알고리즘을 이용해 오름차순으로 정렬하고, 정렬 전후의 배열 상태를 출력하는 프로그램입니다.

## 주요 풀이 아이디어
1. 정렬 함수 구현: bubbleSortAscending 함수를 만들어 이중 반복문으로 인접한 두 원소를 비교하고, 앞의 원소가 더 크면 값을 교환합니다.
2. 배열 크기 계산: sizeof 연산자를 활용하여 배열 전체 크기를 자료형 크기로 나누어 원소의 개수를 동적으로 구합니다.
3. 초기 상태 출력: 정렬을 수행하기 전의 배열 원소들을 포맷에 맞춰 출력합니다.
4. 결과 출력: 정렬 함수를 호출한 뒤 오름차순으로 정렬된 배열을 차례대로 출력합니다.
