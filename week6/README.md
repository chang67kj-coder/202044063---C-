C 언어 정렬 알고리즘 (내림차순)

본 문서(또는 저장소)는 C 언어를 사용하여 구현된 기본적인 정렬 알고리즘에 대한 내용을 담고 있습니다. 모든 알고리즘은 내림차순 정렬을 기준으로 작성되었습니다.

포함된 알고리즘

선택 정렬 (Selection Sort)
정렬되지 않은 배열 부분에서 최댓값을 찾아 맨 앞의 원소와 교환하여 정렬을 수행하는 방식입니다.

삽입 정렬 (Insertion Sort)
두 번째 원소부터 시작하여, 그 앞의 이미 정렬된 부분과 비교해 자신의 알맞은 위치를 찾아 삽입하는 방식입니다.

# 별 출력 프로그램

C 언어의 중첩 `for`문을 이용하여 별(`*`)을 계단식으로 출력하는 프로그램입니다.

## 실행 결과

```text
*
**
***
****
*****
```

## 사용 문법
- `for` 반복문
- 중첩 반복문
- `printf()`
